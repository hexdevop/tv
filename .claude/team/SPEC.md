# ТЗ: своя прошивка для ТВ SmartTV235X

## Функциональные требования
- **FR-001** Удалить вредоносное ПО и не допустить повторного заражения.
- **FR-002** Полный бэкап всех разделов на ПК с проверкой sha256 до любых изменений.
- **FR-003** Убрать ненужные системные приложения (сначала `pm disable-user`, физическое удаление из `/system` позже).
- **FR-004** Свой лаунчер (домашний экран) для Android TV: Kotlin + Jetpack Compose for TV, управление пультом.
- **FR-005** Свои меню и настройки: картинка, звук, источник входа, сеть. Работают через API HiSilicon (`com.hisilicon.tv.service`).
- **FR-006** Встроить лаунчер в `/system/priv-app` как системный, заменить лаунчер Zeasn.
- **FR-007** Свои логотип и анимация загрузки (`logo`, `bootanimation`, `bootmusic`).
- **FR-008** Сетевой adb оставить только для ПК разработчика (сейчас открыт всем).

## Нефункциональные требования
- **NFR-001** Всё делается по сети (adb по Ethernet/Wi-Fi), без вскрытия ТВ.
- **NFR-002** Каждый шаг обратим. Разделы из «запретного» списка в ARCHITECTURE.md не трогаются.
- **NFR-003** Лёгкий UI: 1 ГБ RAM, 32-битный ARM, 720p. Только `armeabi-v7a` или чистый JVM-код.
- **NFR-004** Картинка, звук, пульт, YouTube, Allplay и TelecomTV должны продолжать работать.

## Вне рамок
- Сборка AOSP или ядра из исходников (нет BSP).
- Изменение загрузчика, TrustZone и калибровки панели.

## Допущения
- AVB отключён, и изменённый `/system` загрузится (проверить до FR-006).
- Recovery позволяет откатиться с USB-флешки (проверить, не меняя разделов).

- Дизайн лаунчера: референсы и пожелания пользователя.
